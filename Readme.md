# Blinkit Grocery Sales Analysis (Excel Dashboard)

## 📌 Project Overview
This project focuses on analyzing **Blinkit grocery sales performance** using an interactive Excel dashboard. The goal was to evaluate revenue, customer satisfaction, and outlet performance across multiple dimensions such as item type, fat content, outlet size, and location.

## 🎯 Objectives
- Track key performance indicators (KPIs) to monitor sales and customer satisfaction.
- Compare item sales across categories, fat content, and outlets.
- Identify trends in sales by outlet size, location, and establishment year.
- Provide a comprehensive view of performance using interactive charts and KPIs.

## 📊 KPIs Tracked
1. **Total Sales** – Overall revenue generated.  
2. **Average Sales** – Average revenue per sale.  
3. **Number of Items** – Total count of items sold.  
4. **Average Rating** – Customer satisfaction score.  

## 📈 Key Insights
- **Regular items** generated higher sales than low-fat items.  
- **Top-selling categories** included Fruits & Vegetables, Snacks, and Beverages.  
- **Newer outlets (post-2015)** showed growth in sales, while older outlets stabilized.  
- **Medium-sized outlets** were the strongest revenue contributors.  
- **Tier 3 locations** showed surprising sales strength, highlighting semi-urban growth potential.  
- **High customer ratings (~4–5)** indicate strong satisfaction.  

## 🛠️ Tools & Techniques
- **Microsoft Excel** – Pivot Tables, Charts, Conditional Formatting, Slicers.  
- **Dashboard Visualizations** – KPI Cards, Donut, Bar, Line, Funnel, and Matrix Charts.
